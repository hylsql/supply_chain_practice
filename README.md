# Supply Chain SQL Practice Package

A comprehensive hands-on SQL practice project designed to build job-ready skills for Supply Chain Analyst, Operations Analyst, Inventory Analyst, and Business Analyst roles.

This project includes realistic supply chain datasets with intentional data quality issues, 100 SQL practice questions with detailed solutions, and Python automation examples.

---

## Project Objectives

- Master SQL for data cleaning and analysis
- Practice real-world supply chain KPIs
- Automate reporting with Python
- Develop a portfolio project for analyst roles

---

## Skills Covered

### SQL
- Data cleaning and validation
- Joins and aggregations
- Window functions
- Common Table Expressions (CTEs)
- Ranking and segmentation
- KPI calculations

### Supply Chain Analytics
- Inventory Turnover
- Days on Hand
- Fill Rate
- Lead Time
- Freight % of Revenue
- ABC Analysis
- Stockout Rate
- Supplier Performance

### Python
- Load CSV files
- Connect to PostgreSQL
- Execute SQL queries
- Export reports
- Automate workflows

---

## Dataset Overview

The package contains realistic supply chain data with duplicates, missing values, inconsistent text, invalid dates, and outliers.

| File | Description |
|------|-------------|
| products.csv | Product master and cost data |
| inventory.csv | Warehouse inventory balances |
| suppliers.csv | Supplier information |
| purchase_orders.csv | Purchase order transactions |
| shipments.csv | Freight and delivery data |
| customer_orders.csv | Sales order data |
